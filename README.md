# DM

Неофициальная некоммерческая браузерная фан-игра по мотивам Dota 2 (12+).

**Играть:** https://dm-rouge.vercel.app/

## Что это
Прокачка героев, коллекция скинов и снаряжения, арена из 250 уровней, PvP и режим «Путь Древнего». В игре есть мини-игры со слотами и сундуками.

## Важно
- Только игровая валюта (кристаллы): их нельзя купить, пополнить или вывести.
- Нет платежей, доната и обмена на реальные скины, коды и призы.
- Пароль хранится только в этой игре. Не вводи пароли от других сервисов.
- Dota 2 — собственность Valve. Проект с Valve не связан.
